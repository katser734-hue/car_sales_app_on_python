# Учет продаж автомобилей

Учебный проект на Python: десктопное приложение для учета продаж автомобилей, клиентов и консультантов.

## Стек
Python, tkinter (интерфейс), sqlite3 (база данных), datetime.

## Функционал
- Добавление, редактирование, удаление и просмотр записей: клиенты, консультанты, марки, машины, скидки, покупки.
- Связанные таблицы с внешними ключами.
- Поиск по нескольким параметрам: клиент, консультант, авто, дата.
- Просмотр проданных и непроданных автомобилей.
- Генерация HTML-отчета со статистикой продаж по маркам.

## Запуск
1. Установить Python 3.8+.
2. Запустить файл fail.py: python fail.py.
3. При первом запуске создается база данных databd.db и все таблицы.

## Навыки
Проектирование реляционной базы данных, SQL-запросы (JOIN, агрегации, подзапросы), интерфейс на tkinter, обработка ошибок и валидация ввода, автоматизация отчетов.
